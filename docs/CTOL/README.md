# docs/CTOL

CTOL（在线 CT AI 检测）接手与改造资料。

## 怎么用（新会话）

1. **只拖拽** [CTOL进度存档.md](./CTOL进度存档.md)（索引 + 当前状态）
2. 需要规格 / 代码地图 / 本期改造时，按存档 **§0 文档索引** 打开规划、改造指南或接手指南
3. 追溯历史时再打开 [CTOL版本变更记录.md](./CTOL版本变更记录.md)
