## 3. 平台约束与模块形态

### 3.1 分层原则

| 层 | 职责 | 禁止 |
|----|------|------|
| View | 布局、控件、绑定 | 业务计算、PLC 读写、写文件 |
| ViewModel | 命令、状态、把服务数据绑定到界面 | 直接 `new` 通讯/存储类、硬编码地址 |
| Service（`Services/Project/AIPredictive/`） | 采集、计算、落盘、对外调用 | 依赖具体 Page |
| Core 接口 / 模型 | 契约与 DTO | 引用 WPF |

对照规范：[代码开发规范](../代码开发规范.md)。

### 3.2 模块形态（已落地）

```
SUNWODA_SEVB/
├── ViewModels/Pages/AIPredictive/VM_AIPredictivePage.cs   ← 已建：[Module("VM_AIPredictivePage", "AI预测分析")]
└── Views/Pages/AIPredictive/
    ├── AIPredictivePage.xaml                              ← 已建：空态页面
    └── AIPredictivePage.xaml.cs                           ← 已建：partial class，仅构造函数

Services/Project/AIPredictive/          ← 待建（业务服务）
Core/Interfaces/Project/AIPredictive/   ← 待建（接口契约）
Core/Models/Project/AIPredictive/       ← 待建（DTO / 配置模型）
```

三个名字必须一致：VM 类 `VM_AIPredictivePage` ↔ `x:Class="SUNWODA_SEVB.Views.Pages.AIPredictive.AIPredictivePage"` ↔ `partial class AIPredictivePage`。
