# NCLCCT 开发资料（原始投放区）

> **用途**：投放本项目现场/对接**原始资料**（PLC 点位表、设备信息、工艺阈值表、截图、对接说明等）。  
> **整理后**：由工作流「开始录入」或 Agent 按规程 §2.2 整理为 `NCLCCT项目开发规划.md` 对应章节与上级目录下的 CSV。  
> **当前状态**：**未录入**（等待投放，详见规划 §0）。

## 放入这里

- 现场 PLC 点位表 / 设备信息表 / 工艺参数或阈值表（原始 Excel、csv、pdf、截图）
- 对接方提供的接口文档、算法说明、通信协议说明
- 现场照片、可检索的说明类文件

## 不要放入这里

- 无关压缩包、整仓备份
- 大体积 DLL（按平台约定目录）
- 已整理定稿的 CSV 重复拷贝（整理后的真相放上级 `docs/NCLCCT/` 根下，由规划 §0 索引）

## 录入标识

- 首次录入 / 跳过录入后，工作流写入本目录 `.swd-materials-status`（`ingested` / `skipped`）。
- 再次投放新资料后走「更新录入」（增量补差，禁止从零重整理）。
