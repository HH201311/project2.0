## 检材

| 标签 | 数量 | 说明 |
|------|------|------|
| 白标签 | ×2 | 含二维码 + 多行文本 + PACK 编码 |
| 铭牌 | ×1 | 底部「产品编码」须与白标签 PACK 编码一致 |

## 扫码完成后上位机校验（必做 · 顺序）

1. **码一致**：文件夹 SN == 白标签产品码 == 铭牌产品码 == **白标签二维码**；失败时预览图左上角叠 NG  
2. **长度**：恰好 24 位  
3. **前十位档位**：码前 10 位 == 当前设置档位前缀
