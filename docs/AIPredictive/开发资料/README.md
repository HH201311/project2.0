## 录入方式

按工作流「开发资料 → 开始录入」（或规程 §2.2 的「开始录入」Prompt）执行；录入后由 Agent：

1. 阅读本目录业务文件（跳过 `.swd-*` 标识文件）  
2. 把已知事实整理进 [AIPredictive项目开发规划.md](../AIPredictive项目开发规划.md) 对应章节，点位/设备/参数落为 CSV（放上级目录，勿在此重复拷贝）  
3. 更新进度存档 §0 索引；未知项标 ⏸，禁止臆造  

> **CSV 转换口径**（已用于 `伺服.txt` / `气缸.txt`，后续资料沿用）：纯文本/表格 → **UTF-8 with BOM + CRLF + RFC4180**，首行列名；**字段顺序、字段值、空字段、行序保持与源文件一致**；不改写、不补全、不推断语义。
