## 2. 命名语义（相机 / 张序）——已按现场口径校正

统一文件名：

```text
{SN}-{相机名}-{张序}-{结果}_{yyyy-MM-dd-HH-mm-ss-fff}.jpg
```

| 字段 | 含义 | 示例 |
|------|------|------|
| SN | 与父文件夹名一致 | `12TPB09LABP0SDG9A3300002` |
| **相机名** | **一台相机的名字**（不是「工位类别」） | `长右1`、`底3`、`前` |
| **张序** | **该相机拍的第几张** | `长右1-1` = 相机「长右1」的第 1 张；`长右1-2` = 第 2 张 |
| 结果 | `OK` / `NG` | 本次 dump 几乎全 `OK` |
| 时间戳 | 毫秒级本地时间 | `2026-09-10-23-19-15-011` |

**特例**

- Z：偶见 `…-定位-…` 或目录 `1\` 下文件——**非相机**，监视/路由时可忽略或单独处理。
- 同一 `{相机名}-{张序}` 可能因重触发出现**多个时间戳文件**（统计「设计张数」以张序上限为准，不以文件个数简单相加）。

## 4. 监视与路由建议

1. 监视根：**`Y:\OK原图`**、**`Z:\OK原图`**（递归日期/SN）。  
2. 路由键：**相机名**（文件名第二段），例如白标签/铭牌按 `前`/`底*`/`长*` 等关键词映射到工位，**不要**把 `长右1-1` 当成另一台相机。  
3. 同一相机多张：用 **张序** 区分帧；去重时可用 `(SN, 相机名, 张序)`，保留最新时间戳。  
4. 文件名含 `定位` / 目录 `1`：**非相机**，码检路由默认忽略。  
5. 同级 `NG原图` 命名规则预期相同；本期 dump 未统计 NG。

## 6. 开发结论（修订后）

1. **监视两个文件夹**：`Y:\OK原图`、`Z:\OK原图`。  
2. **12 台相机**（不含「定位」）；文件名中段是**相机名**，其后数字是**该相机第几张**。  
3. **每相机设计张数**：前/后=4；底1～4=6；上左/上右=2；长左*/长右*=4。  
4. 单包设计 **52 张**（跨 Y+Z）；重拍会使文件数偏多。  
5. 全量列表仍以 `Y盘.txt` / `z盘.txt` 为准。
