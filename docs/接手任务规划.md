## 3. 学习策略（核心原则）

> **先锁定自己负责的产线项目，跟业务代码走；平台机制遇到问题时再查架构文档。**

```
阶段 1：平台约定 + Demo 模板        →  能新增/修改标准业务页
阶段 2：跟负责项目的 Services 层     →  理解 PLC / Python / Socket / DB 数据流
阶段 3：按需深入框架底层             →  能改导航、启动、DI 注册
```

**不要第一天就啃**：`ModuleManager` 反射细节、全部 40+ 业务模块、Halcon/ONNX 算法内部实现。  
**遇到平台行为问题时查**：`docs/项目架构说明.md` 第 15 节常见问题。

## 5. 立即操作备忘

### 5.1 启用业务模块（开发环境）

```sql
USE sunwoda_demo;

-- 启用全部模块
UPDATE workspace_project SET is_enabled = 1;

-- 或仅启用指定模块
UPDATE workspace_project SET is_enabled = 1
WHERE vm_class_name IN (
    'VM_DevelopProjectDemoPage',
    'VM_MachineDamageMonitoringPage',
    'VM_CCTBMonitoringPage'
);
```

修改后 **完全退出并重启应用**。

### 5.2 选择主窗口类型

```sql
-- 通用平台主窗口（左侧标准导航，适合熟悉多模块）
UPDATE global_setting SET value = 'MainWindow' WHERE name = 'AppStartMainWindow';

-- 涂布闭环专用主窗口（CCTB 产线调试）
UPDATE global_setting SET value = 'CCTBMainWindow' WHERE name = 'AppStartMainWindow';
```

### 5.3 配置 Python 环境（CCTB / JRCW / 容量预测等）

```sql
UPDATE global_setting SET value = 'true'  WHERE name = 'IsInitPythonEnvironment';
UPDATE global_setting SET value = 'C:\\Python311' WHERE name = 'PythonInstallDir';
-- 路径改为本机 64 位 Python 实际安装目录
```

保存后 **重启应用**。详见架构说明 §9。

### 5.4 设置默认打开模块（可选）

```sql
UPDATE global_setting
SET value = 'VM_DevelopProjectDemoPage'
WHERE name = 'DefaultProject';
```

### 5.5 首次编译 checklist

```
□ dotnet restore SUNWODA_SEVB.sln（或 VS 还原 NuGet）
□ 确认 .NET 8 SDK + VS「.NET 桌面开发」已安装
□ MySQL 已启动，appsettings.json 连接串正确
□ 若跑 AI/视觉模块：补齐 SUNWODA_SEVB.Core/Dlls/ 原生库
□ 若跑 CCTB：Python 64 位 + IsInitPythonEnvironment=true
```

## 6. 业务开发速查清单

### 6.1 新增标准业务页（通用主窗口）

```
□ ViewModel 添加 [Module("VM_Xxx", "显示名")]
□ ViewModel 继承 ViewModelBase，构造函数注入服务
□ View 命名与 ViewModel 对应（去掉 VM_，ViewModels→Views）
□ OnNavigatedTo 加载数据，OnNavigatedFrom 清理
□ 重启 → workspace_project 写入新记录
□ UPDATE workspace_project SET is_enabled = 1
□ 再次重启确认菜单显示
```

### 6.2 新增产线项目服务

```
□ 接口定义在 SUNWODA_SEVB.Core/Interfaces/Project/<项目>/
□ 实现放在 SUNWODA_SEVB/Services/Project/<项目>/
□ 在 ProjectServiceCollectionExtensions.AddProjectServices() 注册
□ ViewModel 通过构造函数注入接口（不要直接 new 实现类）
```

### 6.3 CCTB 子模块（多级导航）

```
□ [Module] 的 Category 设为 "父模块名/子模块名"
□ 在 CCTBMainWindow 下通过 AutoRegisterModulesByName 局部加载
□ 参考 VM_SummaryPage、VM_TBDataPage 的 Category 写法
```

## 8. 问题与笔记（持续更新）

### 2026-07-06

- **问题**：首次启动侧边栏只有设置和用户。  
  **结论**：`workspace_project.is_enabled` 默认仅 Settings/UserCenter 为 1，需 SQL 启用。

- **问题**：编译报 CS0246 找不到 HslCommunication、OpenCvSharp 等。  
  **结论**：NuGet 未还原；`dotnet restore` 或 VS「还原 NuGet 程序包」即可。MQTT 类型来自 `HslCommunication.MQTT`，无需单独装 MQTTnet。

- **问题**：启动提示「未开启 Python 环境初始化开关」。  
  **结论**：打开 CCTB 等模块时 `AlgorithmService` 要求 `IsInitPythonEnvironment=true`，且需配置 `PythonInstallDir` 后重启。完整原文为「未开启 Python 环境初始化开关！」。

- **问题**：设置页「项目设置」下拉为空。  
  **结论**：下拉只列已启用项目，须先在 DB 启用模块。

- **develop 备忘**：解决方案新增 `SUNWODA_SEVB.WatchDogService`；`ConfigTool` 存在但未纳入 sln；MES 不再在 App 启动时显式初始化。

- **LiWeiTest 练手**：新增 `VM_TestPage` / `TestPage`；踩坑包括 `x:Class` 与 partial class 不一致（`InitializeComponent` 报错）、WSL/Windows 文件不同步。详见 `docs/LiWeiTest入门复盘与明日学习计划.md`。
