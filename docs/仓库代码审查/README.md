# 仓库代码审查

傻瓜式用法：把 **[一键代码审查.md](./一键代码审查.md)** 拖给 Agent，回「全部默认」或答几道题即可。

| 文件 | 说明 |
|------|------|
| [一键代码审查.md](./一键代码审查.md) | **唯一入口**：完整 Prompt（先问答再审查） |
| [审查策略-需求点检与单元测试.md](./审查策略-需求点检与单元测试.md) | **审查策略**：不加审查环节；用每项目「需求点检表」+ 关键逻辑单测验证"是否真的实现、是否真的生效"；审查收窄为触发式短清单 |
| `审查报告-YYYYMMDD-HHmm.md` | 框架/多项目报告落于此；单产线优先 `docs/<项目>/`（仅命中审查策略 §4 触发条件时产出） |

写法标准见 [代码开发规范](../代码开发规范.md)。
