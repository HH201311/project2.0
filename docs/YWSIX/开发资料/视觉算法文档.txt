三、白标签四码解码
3. DecodeThreeCodesByOCR（带编码规则）
public string DecodeThreeCodesByOCR(
    HObject inputImage, string productSNRule,
    out HObject qrCodeRegion, out HObject partSNRegion,
    out HObject productSNRegion, out HObject versionRegion,
    out string qrData, out string partSN, out string productSN, out string version)
功能：定位二维码并解码，同时 OCR 识别零部件序列码、产品编码、版本号。
输入参数
参数
类型
说明
inputImage
HObject
白标签图像
productSNRule
string
产品编码规则：'L'=大写字母，'D'=数字，其他字符=指定分隔符。例 "LLDDDDDD"（前2位字母+后6位数字）；传空串 "" 则不做位置校正
输出参数
参数
类型
说明
qrCodeRegion
HObject
二维码区域（调用方释放）
partSNRegion
HObject
零部件序列码区域

HObject
产品编码区域
versionRegion
HObject
版本号区域
qrData
string
二维码解码内容
partSN
string
零部件序列码（纯数字）
productSN
string
产品编码（数字+大写字母，按规则校正）
version
string
版本号（如 M00，仅 O→0 校正）
返回值：string — 空 "" 成功；失败信息如 "未找到二维码"、"零部件序列码OCR失败: ..."、"产品编码OCR失败: ..."、"版本号OCR失败: ..."、"异常"。

五、上盖检测
7. DetectTopCover
public string DetectTopCover(
    HObject inputImage, string modelPath, string[] classNames,
    out List<AIResults> results, bool useGpu = false)
功能：使用 YOLO26 检测图像中的上盖区域，返回所有检测到的目标。
模型文件：YW_X01_TOP.onnx
类别名称：["sealing_foam", "hanger_bushing"]（须与模型训练时类别顺序一致）
输入参数
参数
类型
说明
inputImage
HObject
输入图像（支持灰度/彩色）
modelPath
string
YOLO26 模型文件路径（模型文件：YW_X01_TOP.onnx）
classNames
string[]
类别名称数组，须与模型训练时类别顺序一致（["sealing_foam", "hanger_bushing"]）
useGpu
bool
是否 GPU 推理，默认 false
输出参数
参数
类型
说明
results
List<AIResults>
检测结果列表。Name=类别标签，Region=区域，Score=置信度。调用方负责遍历 Dispose() 每个 Region
返回值：string — 空 "" 成功；"图像转换失败"、"未检测到上盖"、"异常: ..."。
线程安全：检测器为单例（按模型路径缓存），推理调用受 lock 保护，多线程调用时串行执行。

六、连接器 PIN 针歪斜检测
8. DetectConnectorPinSkew
public void DetectConnectorPinSkew(
    HObject ho_Image,
    out HTuple hv_LongPinAngleDiff,
    out HTuple hv_LongPinColDiff,   out HTuple hv_LongPinRowDiff,
    out HTuple hv_ShortPinRowDiff,  out HTuple hv_ShortPinColDiff,
    out HTuple hv_LongPin1CenterRow, out HTuple hv_LongPin1CenterCol,
    out HTuple hv_LongPin2CenterRow, out HTuple hv_LongPin2CenterCol,
    out HTuple hv_ShortPin1CenterRow, out HTuple hv_ShortPin1CenterCol,
    out HTuple hv_ShortPin2CenterRow, out HTuple hv_ShortPin2CenterCol)
功能：检测连接器 4 根 PIN 针（2 长 2 短）的中心位置，计算歪斜指标。检测失败时输出值为 0。
输入参数
参数
类型
说明
ho_Image
HObject
连接器图像
输出参数（全部为 HTuple，取数值用 .D）
参数
类型
说明
hv_LongPinAngleDiff
HTuple
两根长 PIN 角度差（度，已处理角度周期性，0~90°）
hv_LongPinColDiff
HTuple
两根长 PIN 中心列坐标差（像素，绝对值）
hv_LongPinRowDiff
HTuple
两根长 PIN 中心行坐标差（像素，绝对值）
hv_ShortPinRowDiff
HTuple
两根短 PIN 中心行坐标差（像素，绝对值）
hv_ShortPinColDiff
HTuple
两根短 PIN 中心列坐标差（像素，绝对值）
hv_LongPin1/2CenterRow/Col
HTuple
两根长 PIN 中心坐标
hv_ShortPin1/2CenterRow/Col
HTuple
两根短 PIN 中心坐标
返回值：void。检测失败（未找到 PIN 针）时，对应输出值保留初始值 0.0，无异常抛出。
NG 判定工艺范围（示例值，实际由工艺工程师调整）
指标
判定方式
OK 范围
单位
长 PIN 角度差（hv_LongPinAngleDiff）
≤ 阈值 OK
≤ 2.0
度
长 PIN 列差（hv_LongPinColDiff）
≤ 阈值 OK
≤ 8.0
像素
长 PIN 行差（hv_LongPinRowDiff）
区间 OK
[240.0, 260.0]
像素
短 PIN 行差（hv_ShortPinRowDiff）
≤ 阈值 OK
≤ 5.0
像素
短 PIN 列差（hv_ShortPinColDiff）
区间 OK
[45.0, 65.0]
像素
5 项指标全部满足才判 OK，任一不满足即 NG。本方法只负责检测与指标计算，NG 判定由调用方执行。

七、调用示例
7.1 上盖检测
using YWX01Pack;
using HalconDotNet;

AI ai = new AI();
HOperatorSet.ReadImage(out HObject image, @"D:\images\test.jpg");

string err = ai.DetectTopCover(
    image,
    @"D:\models\YW_X01_TOP.onnx",
    new[] { "上盖" },
    out List<AI.AIResults> results,
    useGpu: false);

if (err == "")
{
    foreach (var r in results)
    {
        Console.WriteLine($"{r.Name} 置信度={r.Score:F2}");
        HOperatorSet.DispObj(r.Region, windowHandle);
        r.Region.Dispose();
    }
}
else
{
    Console.WriteLine($"检测失败: {err}");
}
image.Dispose();
7.2 PIN 针歪斜检测
ai.DetectConnectorPinSkew(image,
    out HTuple angleDiff, out HTuple lColDiff, out HTuple lRowDiff,
    out HTuple sRowDiff,  out HTuple sColDiff,
    out HTuple l1Row, out HTuple l1Col, out HTuple l2Row, out HTuple l2Col,
    out HTuple s1Row, out HTuple s1Col, out HTuple s2Row, out HTuple s2Col);

double angle = angleDiff.D;
// ... 自行按工艺阈值判定 OK/NG

angleDiff.Dispose(); /* ... 释放所有 HTuple ... */
7.3 白标签四码解码
string err = ai.DecodeThreeCodesByOCR(image, "LLDDDDDD",
    out HObject qrRegion, out HObject partSNRegion,
    out HObject productSNRegion, out HObject versionRegion,
    out string qrData, out string partSN, out string productSN, out string version);

if (err == "")
{
    Console.WriteLine($"二维码: {qrData}");
    Console.WriteLine($"零部件序列码: {partSN}");
    Console.WriteLine($"产品编码: {productSN}");
    Console.WriteLine($"版本号: {version}");
}
qrRegion?.Dispose();
partSNRegion?.Dispose();
productSNRegion?.Dispose();
versionRegion?.Dispose();
