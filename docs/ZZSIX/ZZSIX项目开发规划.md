## 1. 项目定位与目标

### 1.1 业务定位

**ZZSIX** 为产线业务模块（具体工序与价值待资料补齐），运行于欣旺达 SEVB 统一桌面平台。

当前阶段目标：完成菜单可进的空页骨架与文档体系，便于后续按资料迭代功能。

### 1.2 本期范围（P0 骨架）

| 能力 | 是否本期 | 说明 |
|------|----------|------|
| 菜单空页 demo | ✅ 已做 | `VM_ZZSIXPage` / `ZZSIXPage`，菜单名「ZZSIX」 |
| 三文档 + 开发资料目录 | ✅ 已做 | 对照 BoxGluing 热/冷层分工 |
| 模块启用 SQL | ✅ 已做 | `enable_zzsix_module.sql` → `sunwoda_demo` |
| 业务采集 / 曲线 / 算法 | ❌ 未启动 | 等开发资料录入后定范围 |

### 1.2.1 当前进度

**见 [ZZSIX进度存档.md](./ZZSIX进度存档.md)**，不在本文重复维护。

### 1.3 明确不做（本期骨架）

- 不臆造 PLC 点位、IP、阈值
- 不提前引入采集服务 / 图表 / 算法接口（无资料前不做）
- 不修改平台公共壳与其它产线模块
