### 1.1 检测项 · 三码校验（详）

- **一项三图**：前-1、长左2-2、前-3 都算 **同一个检测项「三码校验」**（内部分三通道并行，对外不拆分统计）。  
- **一句话规则**：以文件夹码为基准；白标签①/②产品码、铭牌产品码、白标签二维码各自只与文件夹比对；文件夹码 24 位、前十位对档位；**白标签另：序列码第 3 位 == 产品码第 16 位；版本号 == 设置期望（默认 M00）**。  
- **另**：视觉 DLL 读失败 → 帧 NG（仍归本项）；算法异常进「视觉算法异常」。  
- **联调**：🔄 现场样张（含长左2-2）  
- **代码入口**：`Pack6ZztwVisionEngine` / `Pack6BarcodeRuleValidator` / `Pack6WorkClassifier` / `Pack6DefectFolderMapper`  
- **详规**：规划 §1.1.2～§1.1.3；[校验规则/README.md](./开发资料/校验规则/README.md)
