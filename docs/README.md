# docs — 项目文档

各产线/业务模块在 `docs/<项目名>/` 下维护文档。

## 唯一约定：进度存档 = 索引热层

| 文件 | 角色 | 新会话 |
|------|------|--------|
| `<项目>进度存档.md` | **热层**：状态、待办、代码入口、**指向详规的索引** | **只拖这份** |
| `<项目>版本变更记录.md` | **变更历史**：背景 / 做法 / 落点（按日倒序） | 追溯时按索引打开 |
| `<项目>项目开发规划.md` | **冷层详规**：范围、架构、点位说明 | 按存档索引按需打开 |
| `开发资料/` | **原始资料投放区**（规程 §2.2） | 录入时打开 |
| CSV / SQL 等 | 数据真相（整理后定稿） | 按存档索引按需打开 |

原则：

1. **事实只写一处**（点位写 CSV，架构写规划，进度写存档，历史写版本变更）  
2. 存档用链接索引，**不要双写**  
3. 改完代码：更新存档待办 + 在版本变更记录顶部追加；规格变了再改规划对应节  

参照实例：`docs/BoxGluing/`（三文档 + CSV + 代码入口齐全的样板）。

现有项目：`docs/BoxGluing/`、`docs/CTAutoSlicer/`、`docs/CTOL/`、`docs/ZZSIX/`、`docs/JROH/`。
