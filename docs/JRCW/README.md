# JRCW（卷绕极耳错位闭环）文档目录

卷绕极耳错位闭环业务模块，基于 SUNWODA SEVB（`develop`）平台；单项目多业务（工厂 + 管理器）模式。

## 怎么用（新会话）

1. **只拖拽** [JRCW进度存档.md](./JRCW进度存档.md)（索引 + 当前状态）  
2. 需要架构 / 点位 / 参数时，按存档 **§0 文档索引** 再打开规划  
3. 追溯历史时再打开 [JRCW版本变更记录.md](./JRCW版本变更记录.md)  
4. 任务结束后：更新进度存档待办 + 在版本变更记录顶部追加一条；规格变了再改规划对应节
