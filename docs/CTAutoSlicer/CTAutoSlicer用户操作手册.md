## 使用说明（读手册前）

1. 本文按**界面模块**讲解每个可点击、可输入、可勾选的控件及其作用。
2. 文中「【插图：……】」为图片占位，请在对应位置粘贴实际界面截图。
3. 软件存在两种流水线模式，侧栏菜单会随之变化：
   - **切图模式**：负责 VG 导入、标定、对齐、切片导出，并把「上」视图送检图写入交接目录。
   - **AI标注模式**：不启动 VG，扫描交接目录做 AI 标注、二次手动测距与统计。
4. **生产 / 调试**：生产界面隐藏「单步测试」；调试界面可切换切图/AI，并显示单步测试。

## 二、全局快捷键与流程控制

### 2.1 快捷键一览

| 快捷键 | 作用 |
|--------|------|
| **Alt+O** | 锁定 / 解锁键鼠。点击「开始流程」后默认锁定，防止人员误触干扰自动化。 |
| **Alt+P** | 暂停 / 继续。暂停时自动解锁键鼠，便于检查 VG 画面；再次按下后恢复。 |
| **Alt+X** | 中断当前流程并解锁键鼠。 |

说明：

- 已取消全局 Esc 中断（避免误触）。
- 全屏标定遮罩内仍可用 **Esc** 取消本次标定（与全局热键无关）。

【插图：运行总览中的快捷键说明区】

### 2.2 暂停横幅

流程暂停时，主内容上方会出现红色横幅，提示：「暂停中 — 再按 Alt+P 继续检查后恢复」。

## 五、导入参数（切图模式）

进入方式：左侧导航 → **导入参数**。

### 5.1 路径

| 交互项 | 类型 | 作用 |
|--------|------|------|
| **CT体素文件夹** | 只读路径 + 浏览 | 待处理体积所在目录。支持直接子级 `.vgl` / `.vgi`，以及指向它们的快捷方式 `.lnk`。主流程按创建时间排队。 |

### 5.2 等待与超时

| 交互项 | 类型 | 作用 |
|--------|------|------|
| **快速导入等待(ms)** | 数字 | Ctrl+F+I（或当前版本快捷键）后等待「快速导入」对话框出现的超时 |
| **新建工程等待(ms)** | 数字 | 新建工程后等待保存提示等处理完成的时间 |
| **文件选择等待(ms)** | 数字 | 填路径点打开后，等待文件选择向导出现的超时 |
| **导入超时(分钟)** | 数字 | 单文件「正在导入体积」最长等待；超时则结束该 VG 并保留文件 |
| **导入后稳定等待(ms)** | 数字 | 导入完成后稍作停顿再进入后处理，避免界面未稳定就点渲染/厚板 |

### 5.3 进程池与重试

| 交互项 | 类型 | 作用 |
|--------|------|------|
| **最大VG进程数** | 数字（通常 1～8） | 进程池槽位。导入等待可并行，后处理串行；越大越占内存/显存 |
| **步骤重试次数** | 数字 | UIA 步骤失败时的重试次数 |
| **步骤重试间隔(ms)** | 数字 | 两次重试之间的等待 |

## 七、直方图标定（切图模式）

进入方式：左侧导航 → **直方图标定**。

本页决定导入后如何应用 LUT 预设，以及如何根据直方图峰谷拖动红色阈值线、对齐并扩展 LUT 关键段。

### 7.1 渲染预设

| 交互项 | 类型 | 作用 |
|--------|------|------|
| **正极预设** | 文本 | 文件名含 `-Z` 时选用的 VG 渲染预设名（须与 VG 下拉项名称完全一致） |
| **负极预设** | 文本 | 文件名含 `-F` 或无法识别时默认选用的预设名 |
| **应用预设前等待(ms)** | 数字 | 打开渲染面板、应用预设前的等待 |
| **预设下拉等待(ms)** | 数字 | 打开预设下拉后等待列表项出现的超时 |

【插图：正/负极渲染预设配置】

### 7.2 区域标定（直方图 ROI）

| 交互项 | 类型 | 作用 |
|--------|------|------|
| X / Y / W / H | 只读数字 | 当前直方图 ROI 屏幕矩形 |
| **标定直方图区域** | 按钮 | 隐藏上位机 → 全屏灰遮罩框选直方图区域 → ✓提交 / ✕重选 / Esc 取消。未标定则主流程跳过直方图灰度调整 |
| **预览范围** | 勾选 | 勾选后最小化本软件，在屏幕上高亮当前 ROI，便于核对；Esc 或取消勾选关闭 |

【插图：标定直方图区域与预览范围】

### 7.3 LUT 关键段两点（正/负极）

| 交互项 | 类型 | 作用 |
|--------|------|------|
| 正极/负极 P1X～P2Y | 只读 | 已标定的关键段两端屏幕坐标 |
| **标定正极 LUT 两点** | 按钮 | 建议先在 VG 应用正极预设，再全屏依次点选关键斜段两端；右键/Esc 取消 |
| **标定负极 LUT 两点** | 按钮 | 同上（负极）。运行时按 `-Z`/`-F` 选用对应套；未标定则跳过中点对齐与扩展 |
| **左×Y / 右×Y** | 数字（可小数） | 中点对齐红线后，按峰谷距离 Y 非对称扩展两端的倍数。默认约左 2、右 3；设为 0 可关闭对应侧 |

【插图：标定正极/负极 LUT 两点与左×Y、右×Y】

### 7.4 截图目录与掩膜

| 交互项 | 类型 | 作用 |
|--------|------|------|
| **截图目录** | 路径 + 浏览 | 调试图（原图/对比/峰谷）保存根目录；实际写入「目录\日期」，超过约 7 天自动清理 |

| **容差** | 数字 | 每通道颜色容差。过小漏检、过大易误染面板渐变 |

## 十、切片导出（切图模式）

进入方式：左侧导航 → **切片导出**。

切图模式终点：依次导出「上 / 前 / 右」三视图，并将配置序号的「上」视图图复制到交接目录（硬失败：交接失败则该文件中断）。

### 10.1 导出路径与数量

| 交互项 | 类型 | 作用 |
|--------|------|------|
| **切片导出目录** | 路径 + 浏览 | 三视图切片输出根目录 |
| **上视图交接目录** | 路径 + 浏览 | 两机共享目录。写入 `{交接目录}/{产品名}.jpg`，供 AI 机扫描 |
| **上视图切片序号** | 数字（1～100） | 取「上」视图第 N 张。例如 50 → 源文件常为 `050.jpg`，交接时改名为产品名 |
| **图像宽度** | 数字 | 导出对话框「图像大小-宽」 |
| **导出数量(局部)** | 数字 | 非 QJ 文件的切片数量 |

## 十七、推荐日常操作流程（简版）

### 17.1 切图机（切图模式）

1. 顶部确认 **切图模式**（在**调试**界面下切换；模式会保存在本机配置）。
2. 依次配置 **应用参数 → 导入参数 → 渲染厚板 → 直方图标定 → 视觉对齐 → 对齐后拖拽 → 切片导出**。
3. 首次上机完成全部标定（直方图 ROI、正/负极 LUT 两点、3D/上视图 ROI、简单对齐下拉、偏移 Edit、捕捉按钮与拖拽箭头等）。
4. 在 **运行总览** 点击主按钮开始流程（按钮文案随状态变化，如「开始流程」「运行中…」）。
5. 需要检查 VG 时按 **Alt+P** 暂停；要彻底停止用 **Alt+X**。
6. 出现「需要人工处理」面板时，确认现场后点击 **放入异常文件夹并跳过**。

【插图：切图机开始流程操作示意】

### 17.2 AI 机（AI标注模式）

1. 顶部确认 **AI标注模式**。
2. 在 **AI图像标注** 页配置交接目录、标注结果根目录、模型与像素精度。
3. 手动批处理：在 **运行总览** 点开始；或勾选 **自动执行**，由系统监控交接目录中的 jpg/jpeg。
4. AI 漏检时进入 **二次手动标注** → **打开文件夹开始标注**，在全屏工作台补测距并导出。

【插图：AI 机开始流程 / 自动执行示意】
